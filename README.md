# Competitive Programming & Problem Solving

A structured journey from **programming fundamentals to Data Structures, Algorithms, and Competitive Programming**.

This repository contains my learning notes, implementations, practice problems, and contest solutions developed while building a strong foundation in **C/C++, problem solving, data structures, and algorithmic thinking**.

The goal is not simply to learn syntax, but to understand **how to analyze problems, design solutions, optimize approaches, and implement them efficiently**.

---

## 🚀 Learning Progression

### 01 — C Programming Fundamentals

I started with C to build a strong foundation in programming logic and computational thinking.

**Topics covered:**

* Data Types & Variables
* Input / Output
* Operators
* `if / else`
* Nested Conditions
* `for`, `while`, and `do-while` Loops
* Nested Loops
* Arrays
* Functions
* Recursion
* Basic Problem Solving

This stage helped me understand the fundamentals of programming before moving into more advanced concepts.

---

### 02 — C++ Programming

After developing a foundation in C, I moved to C++ for more advanced programming and competitive programming.

**Topics covered:**

* C++ Syntax & Fundamentals
* Arrays
* Strings
* Functions
* Pointers & References
* Dynamic Variables / Dynamic Memory
* Classes & Objects
* Object-Oriented Programming Fundamentals
* STL concepts and problem-solving techniques

C++ became my primary language for implementing data structures, algorithms, and competitive programming solutions.

---

### 03 — Data Structures

I then focused on understanding how data can be organized and manipulated efficiently.

**Implemented and practiced:**

* Linked List
* Doubly Linked List
* Binary Tree
* Binary Search Tree (BST)
* Tree Traversal
* Insertion & Deletion
* Searching

For each structure, I focused on understanding the underlying logic rather than only using built-in implementations.

---

### 04 — Algorithms & Problem Solving

Alongside data structures, I started studying algorithmic concepts and applying them to programming problems.

**Practice includes:**

* Searching Techniques
* Graph Concepts
* Recursion-Based Problems
* Traversal Techniques
* Algorithm Analysis
* Time & Space Complexity
* Optimization Techniques
* Problem Decomposition

I also practiced recognizing which data structure or algorithm is appropriate for a particular problem.

---

### 05 — Competitive Programming

The final stage of this learning path is applying these concepts to actual programming problems and contests.

**Practice includes:**

* Online Judge Problems
* Algorithmic Challenges
* Data Structure Problems
* Contest Problems
* Implementation Problems
* Time-Constrained Problem Solving
* Debugging & Optimization

The focus is on developing the ability to move from:

**Problem → Analysis → Approach → Algorithm → Implementation → Testing → Optimization**
